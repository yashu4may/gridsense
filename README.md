# GridSense ⚡

AI-powered smart grid load management dashboard — simulates 50 houses across a neighborhood, predicts overload using linear regression, and fairly pauses geysers to protect the grid.

🔗 **Live Demo:** https://gridsense-esp32.streamlit.app

## Features
- Real-time load simulation across 50 virtual houses
- AI-based load forecasting
- Fairness-based load shedding (Jain's Fairness Index logic)
- Live dashboard built with Streamlit + Plotly
